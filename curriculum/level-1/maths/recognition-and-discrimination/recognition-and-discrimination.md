# Recognition & Discrimination

**Description:**
The first step to any path of learning and growth
Is the ability to say things are the same (or not)
This resource provides simple exercises for both
Until patterns and differences are very easy to spot

**Extra:**
All learning begins here. There is no way to teach someone addition if they can't actually recognize numbers or tell them apart. The same is true for letters of the alphabet. And doing exercises or puzzles becomes similarly impossible if the child can't actually distinguish between a right or wrong answer.

The contents of this resource, hence, are very basic (at least when viewed by an adult who has no trouble recognizing numbers and letters) but absolutely crucial to explore.

Once these exercises are second nature, a logical next step is to move towards teaching some first shapes and colors. (They provide a simple, abstracted way to test this skill. Something which many puzzles, games and quizzes can then use.)

**Contents**:
* Connect 2 of the same elements. (And then those lines will create a drawing/mean something/intersect at one of the icons, giving the answer to some question.)
* TARSIAS are great here (as well as with shape/color matching)
* Cut out animals. Place them in the same meadow as each other.
  * Same thing with other clear shapes. Like, put beds inside a bedroom, kitchen stuff inside the kitchen, etcetera. (Like giving a map of the house and then providing icons like "place this thing here!", like a board game)
* **Use shapes/colors, yes, but only identical ones.** They're never actually named or whatever, it's just for recognizing if the same.
* For a given set of things, mark whether they're the same or not.
* GREAT IDEA: Put those things into a grid. Ask to _color in_ the things that are all the same. Have the hint question like "What should we take to get to school?" or something. When done, this reveals a clear _arrow_, which points at the one element around the page that is an actual vehicle to take to school.
* GROUP CIRCLING: Lots of things are given on the page. Draw a circle/closed line around all of the same group (and NONE of another type!) => This allows really coarse motor skills, while being an actual grouping challenge.
* HARDER VERSION of group circling: the animals have different properties (like "tail or not" and "number of legs"), and you group by _property_, still drawing a closed line around it.
