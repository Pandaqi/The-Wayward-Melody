This quiz tests **basic shape knowledge!** The names of shapes, recognizing them in more complex situations, how to manipulate or combine them, and more.

It can be played digitally or physically. (Only a single round _requires_ a computer as it plays sound.) This requires no setup or software: just open the file in any (modern) web browser.

The questions are split into short and focused rounds, and you can easily turn off certain rounds or skip certain questions. This makes it possible to use only a part of the quiz for the specific thing you want to test today.
