# Quiz of Same

## "Question Set: Are these the same?"

Multiple choice questions, only answers are YES or NO.

* Tiger + Tiger (YES)
* Tiger + Giraffe (NO)
* Car + Car (YES)
* Car + Train (NO)
* Happy Face + Sad Face (NO)
* Happy Face + Happy Face (YES)
* Circle + Square (NO)
* Circle + Circle (YES)
* Red Thing + Red Thing (YES)
* Red Thing + Green Thing (YES)

## "Question Set: Which answer is the same?"

Multiple choice questions, one answer matches the image given.

* Tiger Shown => Tiger, Giraffe, Elephant
* Monkey Shown => Monkey, Panda, Hedgehog
* Frowny Face Shown => Frown, Happy, Sad
* Train Shown => Train, Car, Bike
* Red Thing Shown => Red, Green, Blue
* Pink Thing Shown => Pink, Orange, Black
* Square Shown => Square, Circle, Triangle
* Elderly Man Shown => Elderly Man, Elderly Woman, Young Boy, Young Girl
* Young Girl Shown => Young Girl, Young Boy, Elderly Man, Elderly Woman

## "Question Set: Which of these is the odd one out?"

Multiple choice questions, one answer is right (question itsef has no image).

* 2 Circles + 1 Square(!)
* 2 Happy Faces + 1 Sad Face(!)
* 2 Tigers (Identical) + 1 Giraffe(!)
* 2 Elephants (Identical) + 1 Monkey(!)
* 3 Cars + 1 Train(!)
* 3 Bikes + 1 Car(!)
* 3 Sad Faces + 1 Frowny Face(!)
* 3 Giraffes (different poses/stripes) + 1 Elephant(!)
* 3 Monkeys (different poses/stripes) + 1 (Red) Panda(!)
* 3 Blue Things + 1 Pink Thing(!)
* 3 Green Things + 1 Orange Thing(!)

## "Question Set: Which answer matches based on property X?"

Multiple choice questions, one answer is right.

* "Which animal has the same STRIPES/PATTERN?" (x2) => Mix up animals
* "Which animal has equally many TAILS/EYES/WHATEVER?" (x2) => Mix up animals / people
* "Which vehicle has equally many WHEELS?" (x2) => Mix up vehicles
* "Which image has the same COLOR?" (x2) => Mix up animals, faces, vehicles, shapes
* "Which image has the same SHAPE?" (x2) => Mix up animals, faces, vehicles, shapes
* "Which image has the same SIZE?" (x2) => Mix up everything, but at different sizes
