This is a **bundle** with 6 games that all use the same core material. Each game is a unique exploration of basic shapes and how to use them, as well as a different _type_ of game (cooperative, competitive, real-time, simultaneous, team-based, and so forth ...). This means there must be at least one game that fits your specific group of players!

The material is a modified/expanded version of the [Animal Shape Cards](/teachers/level-1/maths/animal-shape-cards). You only need to cut it once to be able to play all games and their variants/expansions.

Every individual game is simple enough that it only needs 1 page of rules (including illustrations, examples and expansions). But don't be fooled by this! We bundled the games to provide you the most value possible and save you from having to print/cut the same material multiple times. Each game is a fun, full, standalone experience that practices strategy and shapes!
