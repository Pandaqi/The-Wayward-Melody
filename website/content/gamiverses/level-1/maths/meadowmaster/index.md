**Meadowmaster** is a grouping game about placing the right animals into the right pens (or "meadows"). With incredibly simple rules, 3D components, and simultaneous physical turns, it encourages Apprentices to practice _grouping_ and _animal knowledge_ in different ways.

At its core, the base game is a simple collaborative exercise in identifying groups. Can kids recognize that all of these are _sheep_? Can kids figure out the moves to get all the _cows_ into the same place?

Once you're comfortable with that, though, you can enable the upgrades for an actual game. They introduce new animals and meadows with special rules that require you to think a lot harder, create different groups, and do things in the right order.

This is probably our **simplest** game in this topic (_My First Groups_). As stated, the base game is barely a game and more of an activity or exercise. If you want to start somewhere in this topic, this game is a good first step. Once players can beat it easily, they are ready for the more challenging games in this topic!
