**Crosscolors** is a unique puzzle developed by us that is a mixture between crosswords and basic color practice. Instead of having to spell a "word", like with crosswords, you need to draw the _colors_ that make up an image in the spaces behind it! As expected, every space can only contain a single color, so you need to also be a little smart with the order in which you draw them.

This mixture creates a real challenge that not only tests if an Apprentice can recognize and name their colors, but also the start of logical thinking and problem solving. All of that can be done with just a basic set of coloring pencils and nothing else. There's not even a need to color inside the lines.

We're very proud that we were able to create a puzzle that works based on _color_, which can already be enjoyed by very young kids. It does require printing in color, of course, using a printer of somewhat acceptable quality.
