# To-Do Curriculum

The specific educational material to create to follow the general curriculum. For now, I only focus on Level 1.

## Level 1

### Social

* A general calendar where you can draw/write an activity to do, and the child/parent can cross it off every day/whenever they do it. _Unique Twist: If you do the thing every day/without fault, some image comes out of the end result?_
  * PUZZLE: The same thing, but now it shows icons on the side of how often you did something that day. And you have to fill up the planning/cross it off to fit the rules of the puzzle. (Example: on monday, it says "2xSchool, 2xExercise", and you must write this into blocks. BUT RULES: no two blocks of the same type may touch horizontally.)
* A general weekplanner meant to write down school stuff and other hobbies. _Unique Twist: Explain to "change it up". The important thing is to have a varied/balanced planning._
* A simple "game" to teach taking turns. 
  * Show an image where the two players _don't_ take turns, with sad faces and stuff.
  * Then show an image where they _do_ alternate, with happy faces.
  * The game itself is just roughly drawing stuff into boxes => maybe combined to tell a story or create a map or whatever. Maybe you draw into _one_ cell on your turn, and all cells combined are one drawing?
* A simple way to encourage "try something new". I'm inclined to use _mazes_ for this => a very simple concept of "try direction A, doesn't work, now try direction B". And these can be explained by simply showing an image of a solved maze + "crossing walls" and sad faces.

### Physical

* Provide a packet with more and more complicated shapes to cut out. => Makes more sense to actually USE the things we cut out in the next exercises ...
* Folding => A simple paper to explain how folding works, some simple exercises that will hide/show something when folded, then move it to an application like folding laundry?
  * Are Origami instructions too early?
* Throwing + Crumpling Paper => This is Fun Frontier territory, no?
* Activities where you give answers by _moving around_ instead of writing or saying them. => This is Fun Frontier territory, no?
* Copying Lines =>
  * Some lines are given around the sides + a dotted line.
  * Draw the exact same line, but now at the dotted line.
  * When done, all those lines combined will create a new image again.
* (Might go further with that and ask you to rotate/flip given shapes. Or draw it again, but twice as larger. Maybe draw it X times, every time larger, so we can now USE that in Math sequencing things.)

### Math

The important part here is to keep it all INTUITIVE and PRACTICAL, related to real-world things a kid understands and finds interesting.

* **Discrimination**: 
  * Connect 2 of the same elements. (And then those lines will create a drawing/mean something/intersect at one of the icons, giving the answer to some question.)
  * Place animals in the same meadow as each other.
  * For a given set of things, mark whether they're the same or not.
  * THEMATIC IDEA: Match "road ends" of tiles with each other, and if you do it right, you get a path from home to school. (Simply explained by showing _wrong_ connections with sad faces.)
* **First Shapes/Colors**: 
  * Discrimination in terms of connecting the same ones with lines or something.
  * BUT, probably more useful, first cut out these shapes/colors and _then_ group them or place them in some way. 
    * (Maybe, if you place all squares in a 2x2, another pattern appears on them.)
    * Colors could be placed on a COLOR CIRCLE, which then reveals something too! (Or, more simply, just place "RED COLOR" token on top of all animal drawings or whatever that have RED in them.)
  * COMBINED: Color all shapes X color Y.
* **Comparing/Sequencing**:
  * Mark the larger group of two (in numbers, in size)
  * Place things in order of length/width/number of eyes/etcetera
* **Grouping**:
  * Draw a circle/closed line around all of the same group?
    * Easy version = they're just completely distinct animals.
    * Harder version = the animals have different properties (like "tail or not" and "number of legs"), and you group by _property_.
    * (Once you've gone through all these versions, another code or result reveals itself? Because of all the groups an animal has been part of? => This works BETTER if we just connect elements by drawing straight lines between, as then you get definite shapes.)
    * **In these things, we really want a HINT at the end about what should magically come out.** (For example, if connecting groups should yield the petals of a flower, then we show some grass and flowers with question marks around it + open space in the middle to draw the flower yourself once you see it.)
  * Cut out elements, place the same ones into the same group. (Then, later, sort those groups by size => as each type appears a unique number of times)
  * Count _groups_ instead of individual elements?
  * DOMINO MATCHING
* **Counting**:
  * CUT OUT things again, then use them to count (and solve simple addition already?)
  * Counting by MARKING => Tallying, "Draw circle for each object of type X that you find", which finally leads to ...
  * Connect numbers with their quantity (through images showing and reinforcing this)
  * Put numbers in sequence too (with a number line and such)
  * Can we start with small Sudokus here? Maybe ones that ONLY do row/column?
* **Numerical Patterns**: 
  * Seasons, Day/Night/Calendar
  * CODE BREAKER puzzles (extremely simple, solve physically) => it's just something like "1 2 4 8" and you give the next number. Or "1 5 8 = COW", and you must translate another set of numbers (this just reinforces alphabet position in its simplest form, or asks you to count the 1st/5th/8th letter in the exercises, or whatever.)
  * (We can quite easily create Season (logic) puzzles => they must follow each other in the right order, and each set of 4 seasons creates a "year", etcetera)

Count to 10, Recognize and name numbers 1–5, Understanding of comparison (more/less, smaller/larger), First Grouping (without counting), First Shapes, First Colors, First introduction to numerical patterns in life (such as seasons)

### Language

Because children can't read/write/recognize letters yet, we're mostly restricted to using SOUND here, and thus QUIZZES. (Maybe we can say that **the other teaching resources can be used as a _bonus/helper_ during the quizzes**? Add option to "randomize" order of questions to prevent memorization over time?)

* "First Vocabulary": have a wizard conjure some spell, but the end result is empty. Teach that "if you say the word, the object becomes it" (so the COW spell creates a COW). Which can later be extended to "if you say the word in CAPITALS, or with a ! after it, etcetera".
* First Syllables: "common blends" of letters. 
  * **Draw around the blend** something that contains those letters. (So you get the empty blend letters as starting point for a drawing.) => This works for **single letters too**, of course.
  * **Read and Mark** => Read a very simple text with lots of images. Keep a word cloud next to it, and cross off any that you find. 
    * Maybe it's a story about stealing or magic or whatever. And it ends with the question "Who stole the cow?", and the answer to that is in the word cloud if you solved it properly!
  * Maybe structure it like a "fight"? Two groups of words before each other, but only proper blends work, so eliminate the others and see who has more?

* "Fill in Alphabet letters" (like Khan Academy)
* Alphabet Letter Memory => Fun Frontier Territory 
* Storytelling => Just Novel Territory?

* QUIZ: Play sounds, they must pick the right option. (Simplest version = show an image of an animal that makes that sound, or a car, and that's what they pick. Advanced Version = Actual words/syllables.)
* QUIZ: Play a song/rhyme, they must pick the option that rhymes. (Simplest Version = Just say _whether_ it rhymes, hearing the full thing. Medium Version = The answers are audio too, and they listen and pick. Hardest Version = Actual words/syllables.)
* QUIZ: Name first/last word in sentence.
* QUIZ: Match first letter on the cover of this book.
* CROSSWORDS/WORD SEARCH can already start here.
