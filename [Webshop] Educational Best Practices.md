# Educational Best Practices

Some general guidelines / roadmaps / notes on how to teach things.

## Maths

### Shape

@SOURCE: https://prek-math-te.stanford.edu/spatial-relations/what-children-know-and-need-learn-about-shape-and-space

The order of learning steps is usually ...

* Discrimination (Sameness and Differences)
* Classification (Grouping based on shared properties, instead of exactly the same)
* Naming
* Understanding
* Composition (Composing and Decomposing complex shapes from simpler shapes)

### Space

@SOURCE: https://prek-math-te.stanford.edu/spatial-relations/what-children-know-and-need-learn-about-shape-and-space

@SOURCE (an example of how a child can have an invalid/incomplete understanding, and how to prompt them to realize some new ways to complete that understanding further): https://prek-math-te.stanford.edu/spatial-relations/sawyers-shapes

The order of learning steps is usually ...

* Absolute Position ("I am on top of the bed", "I am behind the tree", ...)
* Relative Position (Left/Right, X/Y, Height/Width, Symmetry)
* Maps (Symbolism, Scale, Etcetera)

### Numbers/Counting

@SOURCE: https://prek-math-te.stanford.edu/counting/counting-on-counting
@SOURCE: https://prek-math-te.stanford.edu/counting/formative-assessment-it-counts

The five steps to overcome to learn to count:

* One-to-one correspondence between one and only one number word and one and only one object (only one number in the counting sequence is assigned to each object => as in, don't count the same object twice)
* Stable number word order (what digit always comes after what other digit)
* Cardinality (the last number word in the count represents the numerosity of the set)
* Order irrelevance (objects can be counted in any order)
* Abstraction (items, even if dissimilar, can be counted as a set, or a collection of objects). 

If you want to see a toddler's face light up, ask how many eyes or ears she has. These same happy toddlers can also count stairs and share sets of cars fairly (sometimes).

When working with numbers, different strategies are chosen based on the context. (This can be TAUGHT.)

For example, counting is influenced by _set size_. At low quantities, you can instantly see what set is larger. At higher quantities, you need to specifically count it.

As usual, counting is best made _automatic_ by providing diverse counting experiences every day, all through the day. ("Find counting opportunities everywhere.")
