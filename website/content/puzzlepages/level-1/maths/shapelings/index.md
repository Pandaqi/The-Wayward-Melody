**Shapelings** is a unique puzzle developed by us that is a mixture between crosswords and basic shape practice. Instead of having to spell a "word", like with crosswords, you need to draw the _shapes_ that make up an image in the spaces behind it! As expected, every space can only contain a single shape, so you need to also be a little smart with the order in which you draw them.

This mixture creates a real challenge that not only tests if an Apprentice can recognize and name their shapes, but also tests logical thinking and problem solving. All of that can be done with _any_ single pen(cil) and nothing else. The shapes you draw yourself don't need to be straight, or good, or perfect, as long as they're recognizable as the correct shape for that space.

We're very proud that we were able to create a puzzle that works based on _basic shapes_, which can already be enjoyed by very young kids.
