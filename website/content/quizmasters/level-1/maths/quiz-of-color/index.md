This quiz tests basic **color knowledge!** The names of common colors, what you get when you mix them, recognizing them when used in more complicated illustrations, and so forth.

It can be played digitally or physically. (Only a single round _requires_ a computer as it plays sound.) This requires no setup or software: just open the file in any (modern) web browser.

The questions are split into short and focused rounds, and you can easily turn off certain rounds or skip certain questions. This makes it possible to use only a part of the quiz for the specific thing you want to test today. We added a large number of questions just to make sure you'd be able to test every possible part of early color knowledge!
