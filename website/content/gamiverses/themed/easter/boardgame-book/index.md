Already tried all the usual activities during Easter? Exhausted our Busy Book? Then it's time to try this Boardgame Book!

Long ago, we invented a new genre of board games called the "One Paper Game". As the name implies, they're game experiences that you can play just by having a single paper. (And at least one friend, as you can't play any of these games alone.) 

This Boardgame Book contains several of them, all themed around Easter and most suitable for families and (young) children.

* The rules of each game are on the paper itself.
* You either play by writing/drawing on the page, or by using the handful of pawns you cut out.
* Which means setup is incredibly fast and you can easily take the games anywhere.
* And if you exhausted all the games, you can just print the PDF again. That's the beauty of _games_: despite the board being the same each time, the game itself will always be different.

This product contains some classic games with a twist to theme them around Easter, as well as some games we wholly invented ourselves. All of them start really simple, but add "expansions" or "variations" over time to keep it fresh. This means there are 8 unique game types, but around 25 actual (different) games or game boards to play.
