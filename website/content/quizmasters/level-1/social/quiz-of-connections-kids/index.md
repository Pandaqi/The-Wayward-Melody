This quiz has only one type of question, though it plays and experiments with it as much as it can. 

> You are shown a bunch of things. Can you figure out which ones are connected, and **which one doesn't belong?**

This requires being able to discover patterns and similarities between the things. Being able to label them as a certain group, and noticing that only one element doesn't match the group. It's a fun blend of basic skills (comparing, grouping, matching), and some creativity and general knowledge of the world.

This version ("Kids") does all this _without_ text or numbers, but using simple **images, audio and video** that all kids will understand instead. When checking the answers, each question has a short comment explaining _why_ this is the answer. 

Of course, you can "connect" and "associate" in many ways, so the given answer is not necessarily the only one that's correct! If players picked something else, let them explain. And if their explanation is strong enough, reward them too :)

The rounds included are,

* Three Images Round (Easy)
* Three Images Round (Hard)
* Four Images Round (Easy)
* Four Images Round (Hard)
* Audio Round
* Video Round
