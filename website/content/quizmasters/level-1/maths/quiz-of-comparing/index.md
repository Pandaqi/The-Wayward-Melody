This quiz tests your skill in **comparing**. It starts with the absolute simplest version, such as being able to tell that one thing is bigger or smaller than another. With each round, however, the difficulty is increased and the questions become more creative and challenging.

As always, you can play this quiz digitally, physically, or something in-between. It's easy to customize. For example, only play the rounds you want to focus on today, and leave the rest for another time.

The rounds contained within are,

* How Are They Different? (show two things, ask _how_ they differ---establishes that you need some property to compare by)
* Compare Size (pick the option that's _bigger_)
* Compare Rotation (pick the option that's rotated _more_)
* Compare Shape (pick the option that has _more corners_)
* Compare Contents (pick the option that is _more filled_)
* Compare Audio (which one is _louder_)
* Compare Video (which clip is _longer_)
* Sequencing Check (make sure players know what _first/middle/last_ and _before/after_ mean)
* Sort By Size (3/4 items)
* Sort By Color (sort 3/4 colors on a given scale; this is _hard_)
