# This is a test

Wiehoehoo


* **Duration?** (rating) general duration of the entire room (mostly judged on short = 30- minutes, medium = 60-90 minutes, long = 120+ minutes)
* **Difficulty?** (rating) general difficulty of puzzles
* **Outside Knowledge?** (rating) How much external knowledge you need, possibly things you need to look up while playing.
* **Requires Color?** (bool) if puzzles can only be solved if you have it printed in color/aren't colorblind
* **Mature Themes?** (bool) whether it has gore, adult themes, violence, crimes, etcetera
* **Textless?** (bool) whether you need to be able to read (English) to solve puzzles or not. (All kids' escape rooms are textless.)
* **Parallel Puzzling?** (bool or rating?) whether there are multiple puzzles to do at once or everyone has to work together on the same one all the time
* **Can Print Double-Sided?** (bool) if the material still works when printed double-sided => need some way to clearly differentiate "CAN" and "MUST" be double-sided.
* **(Needs) Game Master?** (bool) whether it needs some outside person with knowledge of solutions/secrets to facilitate it
* **Hybrid/Needs Phone?** (bool) probably won't be relevant for this first set of escape rooms I'd make, but still.
* **Different Paper Sizes?** (bool) whether it can be printed on any paper size (besides the default A4). Is true for most escape rooms, but SOME require very exact distances/measurements/etcetera and can't allow this.


* **Linear / Story?** (bool) whether you move linearly through a story, or have free choice on what puzzles to solve and when
* **Preparer Can Play?** (bool) whether the one who prints and cuts out/sets up the puzzles can play themselves. (If not, preparing the material will likely give them clues that ruins playing the game themselves.)
