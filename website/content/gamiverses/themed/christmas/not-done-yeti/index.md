**Not Done Yeti** (previously called _Snowmen!_) is a fun little game about **creating snowmen**. All players walk over the same dangerous frozen map, collecting snowballs of different sizes as they go. At the end, the player who builds the _tallest_ snowman wins.

But, of course, there are rules. Snowman rules. You can only place a _smaller_ circle on top of a _bigger_ one, and snowmen need to end with a _head_! And if you end up with unfinished snowmen? Or you fall through the ice? That won't be great for your score ...

The game is playable by young and old, because it **does not rely on text, color, or numbers**. You only need to compare the raw sizes of the circles and recognize if circles are touching each other. The rules for the base game are only a single page. Expansions add special elements like bridges, action icons, and a cooperative mode.

Because every game has a randomized map---just place snowballs on the table however you like---every game is quick to set up and different to play. Have fun!

{{% remark %}}
The game requires cutting out 3 pages of circular snowballs (in different sizes). That's why "setup" is marked as 2/5 stars (instead of our usual 1/5), because this will take a solid 30 minutes of cutting! Once cut out, of course, you never have to do it again and every new game can be started within 10 seconds.
