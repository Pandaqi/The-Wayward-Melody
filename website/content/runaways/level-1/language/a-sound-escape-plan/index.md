This escape room could be a child's "first escape room". It's entirely based on _sound_, and tests all the basic language skills that Level 1 has been teaching. (Word awareness, syllable awareness, phonemes, etcetera. No alphabet/reading yet, no counting beyond five, no further knowledge required.)

All you need is a (large) space to lay out all puzzles simultaneously, and one computer that can play sound. The Guardian should open the interactive web page (in any browser) and use it to answer questions by the puzzlers.

How does an escape room for such young children work?

* The puzzles are completely based on sound and moving physical tokens/images. (For example, there's one where you must realize you can count syllables in given words, and the end result is a pile of tokens that matches an image.)
* The result of every puzzle is visual, too. If this visual matches something in the web page, click it, and it gives you a new sound ("part of a word").
* If all puzzles were solved correctly, all sounds combined create a thematic word!

This escape room is ideal for large groups or classrooms, because it has "parallel play": one group could be doing puzzle A, while another does puzzle B, while another tackles puzzle C. If you spread the puzzles on different tables (clearly in their "own space"), children can walk around, return when they think they discovered something, etcetera. It is an _escape room_, not just a _puzzle_, which means creative solutions and a cohesive set of puzzles.

The escape room is loosely themed around a dark magical jungle that you're trying to escape. How much you lean into the theme is up to you.

We are incredibly proud of this unique experience. Creating "escape room experiences" for such a young audience has never been done before, because almost all (escape room) puzzles require reading and maths. It took a few tries, but we think we managed to create a short, educational experience that a group of young children can enjoy together.
