_Rhymatch_ is a unique puzzle that creatively tests your rhyming skills. It has 4 "levels" of increasing difficulty, so you start off as easy as possible and they only get harder once you're ready for it. Later levels also add _alliteration_ as a possibility in the puzzle.

We originally developed this puzzle with _words_. (_"You are given two cryptic descriptions of things that rhyme with each other; figure out the secret word(s)."_) Over time, however, we realized there are far too few puzzles for "pre-readers" (young kids who can't read yet). So we made this adapted version too! 

It **only uses images representing simple words.** The "harder" words, whenever present, are the actual _puzzle_---the thing you need to figure out by trying to rhyme it. In a sense, the rhymes are "hints" in the puzzle. This ended up being a very fun way to teach rhyming, alliteration, and simply new words and concept recognition.

_We will release that original Rhymatch (with words) in the near future, once we've started work on Level 2 resources. If we forget to update this page, let us know!_
