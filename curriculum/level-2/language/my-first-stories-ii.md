**Contents**:
* **"Listening Comprehension (Advanced)"**. Read/listen to longer and more complicated stories, and then answer questions or put events in the right sequence.
* **Read and Mark (Advanced)** => Read a very simple text with lots of images. Keep a word cloud next to it, and cross off any that you find. 
  * Maybe it's a story about stealing or magic or whatever. And it ends with the question "Who stole the cow?", and the answer to that is in the word cloud if you solved it properly!
* **Fill in the story blanks (Advanced)** => In the more advanced version, kids would actually write the word into the blanks themselves. (We can do this now with VERY SIMPLE WORDS, ALL CAPS. But it can return again later with more complicated words or entire sentences. NO WE CAN'T, WE CAN'T EXPECT KIDS TO WRITE YET---it's all recognition so far)
* Complete an existing story => Advanced by: Tell your own simple story!

* (Quizmasters) 
  * Give/assign simple stories or "story structures" to students. Then ask questions about the stories. (They can literally read it/look it up; it's about comprehension, not memorization)
    * So, this would be either one story that's an extra page players get ...

* (Puzzlepages) 
  * A story, but with certain parts having a BLANK. The blanks are COLOR CODED, however, and "same color = same word". This allows you to puzzle out what to put in each blank.
* (Runaways) One with an actual story running through it. As you unlock the next puzzle, you get the next "fragment" of the story (just a few sentences). This also allows checking if you did it right (as otherwise the fragment will not make sense)
