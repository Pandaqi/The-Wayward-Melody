Everyone knows them, and once in a while this "challenge" will pop up on social media again. You get some simple image and the deceptively simple question of "how many rectangles do you see?" or "how many triangles in this image?"

If done well, we believe, this is actually a great challenge. If the image is simple enough, and counting the shapes isn't tricksy and annoying, then this is a great exercise. That's why we designed the _Shapeseeing_ bundle, which contains 12 such challenges, which grow harder and harder as you go. 

Because you need to _count_ how often a shape appears, some vague skill with counting is necessary in the Apprentice, even if it's only using their fingers. (Most numbers are around or below 10.)
