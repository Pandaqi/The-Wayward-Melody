# My First Letters

**Description**:
To understand language, take this first step
About letter shapes and order of alphabet
Letters X,X,X,X,X and X are taught
These resources build a strong language ground

**Extra**:

The **"My First Letters"** resource is broken into 4 parts (I, II, III and IV). Each part introduces ~6 more letters, playing with the new shapes and meanings until they are second nature. Once you've explored all 4 parts, your Apprentices have seen the entire alphabet.

This part teaches the letters X, X, X, X, X and X.

Every part also has its own further explorations in the other factions. In fact, we put the bulk of language learning resources into unique puzzles and fun stories. We especially want to highlight [The Alfables](@TODO: Link), which is a bundle of magical fairy tales, each about a single letter! 

As usual, it's recommended to do the resources that come before this one first. In this case, [Phantasy Ponics](/teachers/level-1/phantasy-phonics/) teaches children letter sounds and lays a foundation from which they can connect _alphabet symbols_ to those sounds.

This resource teaches both uppercase and lowercase, as well as variations on how to draw the letter and practical application. When it comes to _recognition_, this is not only doable but preferred. (For example, most language around us includes lowercase letters. And the extra detail sets up the idea early on that letters can look slightly different and still be the same.) Actually _writing_ the letters yourself (by hand) comes much later, and does split uppercase and lowercase.

**These resources are aimed at teaching English.** You can use them in other languages (with a Roman alphabet), but might need to change the order in which letters are taught, and some advanced parts can't be used (because the word doesn't contain the letter in your language).

Alphabet Parts Overview:

* I = s, a, t, i, p, n, c
* II = k, e, h, r, m, d
* III = g, o, l, f, b, q
* IV = u, j, z, w, v, y, x

  * Quiz of Lettersound
    * Which letter has a matching sound? ( = Play a single letter, then pick the option that has the same letter)
    * Which letter has this sound? ( = Play sound of letter/common blend, they pick actual symbol from options.) => Recommend using the "My First Letters" worksheets before this one, otherwise they won't know what each symbol means?
* (Puzzlepages) 
  * LETTERTWIST (I, II, III, IV) => You must place letters (only A,B,C for example) inside a certain grid/shape. BUT letters can never be next to each other in the same rotation, so you need to figure out when to rotate that A to be sideways for example. (Teaches recognition of shapes from many different angles, repetition of drawing the shapes, plus some fun logic.)
    * Start with only NORMAL and UPSIDE-DOWN. Adding LEFT/RIGHT too only complicates stuff and creates too many options.
  * EXPWORDERS => Extremely simple word search (that only requires rough lines to cross things off)
    * + word search strategies as you go? (Look for vowels, look for common blends, use a ruler, spin the page to see it from a different angle, )
  * ALPHAKEY
    * OKAY, SO, MULTIPLE STEPS:
      * First, find the one letter that finishes/completes multiple words. (So you get C_T and H_IR, and the answer is A)
      * Second, find the one letter that finishes two words smashed together. (So you get DO__OAL, and the answer is G for DOG and GOAl.)
      * Third, it's an actual sentence/story with blenks, and a single LETTER finishes it. (That's where we stop; words are for vocabulary?)
