**Morsel Code** (also known as **SOS: Send Help!**) is a game about guessing each other's secret codes. 

Your code is just some random cards (standing up) in a row. These cards use simple **dots** (.) and **dashes** (-), so no knowledge of numbers or letters is needed. Moreover, these codes use a simple rule about **grouping**, teaching this skill in a variety of ways.

What's that rule? Imagine grouping your code by _symbol_ (e.g. `..--` is `..` and `--`).

>  **The code is never allowed to have two groups that are the same!**

So, `--.` is fine. But `--.--` is not, because it has two `--` groups. 

This one simple rule is enough to allow you to make smart guesses and figure out another player's secret code.

At the same time, this is clearly our most "abstract" and "difficult" game out of all our _grouping_ games. We recommend trying one of the other games first if you haven't already. View this as a final test or transition to the next topic (numbers/counting).

You can play the game with 2 players, Guardian (parent / teacher) against child. It's recommended, though, to have at least two players and let the Guardian be the "game master". They can check the code of each player and make sure they're doing it right---but that obviously means they can't actually _play_ the game themselves.

At its simplest, your Apprentices only play this final stage of the game: guess each other's codes!

With the upgrades, however, you can let everyone play the two stages of the game.

* First, they actually _create_ their code themselves. (A deck of cards can randomly add/change the rules for this.)
* Then, they _guess_ the codes of other players. (This can be cooperative---you try to win together---or player versus player and the last one standing wins.)

Finally, if players understand this, it's an easy transition to using the _numbered_ cards. This is a nice first step towards giving your Apprentices counting skills and intuition for _counting elements in a group_.

Have fun and keep learning!

{{% remark %}}
Yes, Morsel Code is a pun on Morse Code and Morsel (a tiny bite or piece of food). We've themed the game around "groups" being "bites from your food" to help reinforce the concept. This theming is quite light and meant in a lighthearted way, though, as this is still clearly a more abstract game.
