# My First Letters

**Description**:
The first step to understanding a word
Is to recognize letter shape and sound
With enough practice and effort
These resources build a strong language ground

**Extra**:
We recommend starting with the digital quizzes instead, which allow **playing sounds**. _Why?_ Firstly, when someone hasn't learned about language yet, they obviously can't do exercises that require reading or writing. Secondly, because our brains have evolved to learn language through _speech_ far more easily than any other way. 

After doing those fun letter sound quizzes, the transition into matching those sounds to visual shapes becomes quite seamless (e.g. using this resource).

Alternatively, you can use many of these resources as extra aids or helpers _while_ using the sound quizzes as the main course, so to speak.

Including sound/speech, and switching up the approach every time, is crucial for another reason: to prevent "superficial" memorization. If you take the exact same test every day---e.g. showing an Apple and asking kids what's the first letter of that word---you risk not teaching anything at all. They simply memorize that they need to say "A" when you show an Apple and that's that. 

**Contents**:
* "Fill in Alphabet letters" (like Khan Academy)
* "Draw around the letter" (something which contains the letter itself, for example: turn the C into a CAT.)
* "Group letters" (Cut out the same letters in all sorts of fonts and styles, then group the letters by same)
* Alphabet Order => one that just _gives it_, and one where you have to cut out letters and put them in right order / connect letters in the right order (like a "connect the dots" but with letters)
* Gestalt Learning => something that presents letters in a wider context/bigger chunks, asking the parent to use them in that larger format too? => This is just what STORIES do, is it not?

**Advanced Spells:** Exhausted this resource? Continue exploring this topic with:

* (Quizmasters) 
  * Sound Quiz ( = Show an image of an animal that makes that sound, or a car, and that's what they pick)
  * Book Covers ( = Match first letter on the cover of this book. This allows weirdly placed/written words, while encouraging interest in books, asking kids if they've read it/want to read this book.)
  * Matching Sound Quiz ( = Play a spoken word, then pick the option with a spoken word that has a matching vowel/syllable) 
  * Quiz of Rhymes Beginner ( = You hear some clip from a song, or two phrases after each other, and must merely say _whether_ it rymes)
  * Letter Sound Quiz ( = Play sound of letter/common blend, they pick actual symbol from options.)
  * Quiz of Rhymes Advanced ( = You hear one bit of audio/one sentence; the answers are audio too; listen and pick the one that rhymes) 
* (Puzzlepages) 
  * Letter Rotation => You must place letters (only A,B,C for example) inside a certain grid/shape. BUT letters can never be next to each other in the same rotation, so you need to figure out when to rotate that A to be sideways for example. (Teaches recognition of shapes from many different angles, repetition of drawing the shapes, plus some fun logic.)
  * Alphakey ( = Find the one letter that, when put into all the blanks, finishes the story; Simplified version would be those "2-side-words" where one letter has to end one word and start the next) 
  * Alphakey Advanced => Cut out an assortment of letters. The exercise tells you which ones to use for this puzzle. You "fill in the blank" by literally placing the letter on top. (And you can't reuse letters of course, so it becomes an extra nice puzzle.)
  * Extremely simple word search (that only requires rough lines to cross things off)
  * IDEA: "Alphabet Order Puzzle" 
    * A crosswords where all you need to do is fill the letters in alphabetic order. (E.g. the row starts with C, so you write D, E, F, G, ...)
    * Some letters are already filled in, and thus lock you into a solution.
    * When done, the contents of all squares marked in some way (colored green or whatever) spell a final word. ("What's another word for a cat?" "FELINE")
* (Runaways) Very simple ciphers, word puzzles and alphabet substitutions. The "code" at the end is just one LETTER? (We can have a cipher/lock with 26 options---all letters---which makes guessing useless.)
* (Gamiverses) Alphabet Letter Memory
