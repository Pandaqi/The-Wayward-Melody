# My First Numbers

**Description:**
Once your apprentice has mastered comparing, sorting and more
It might be time for the real deal, so find the witches
This resource teaches counting using your very first digits
It will be tough but very worth it, so put up your best score!

**Extra:**
This resource is intended to be the final topic in the maths/logic department in level 1. Once people can compare and group "things", they are ready to start assigning numbers to them. To not only say "group A is larger than B", but "group A has 5 items and group B has only 3". In a way, thus far, your apprentice has already been counting, but they just haven't "formalized" it yet (by learning the words and further meaning).

This leap in skill _combines_ the three basic skills of math, language and understanding the world around you. This makes it very natural to some (as the skills help each other grow), but extra challenging for others (as they're overwhelmed by how much to learn). We've tried to provide a wide variety of ways to approach the topic and explore it until things click.

At this stage, though, actual addition (and further operations) is usually too early. This resource, thus, does not consider it.

**Contents:**
* Show a bunch of objects and explain how to _tally_ them. The apprentice must add the right tally below them.
* Do the same but with drawing _circles_ for each (or a simplified icon for them).
* Do the same but with _fingers of your hand_?
  * CUT OUT a bunch of objects. Use those to count. (For every extra object, place one of them on the next square of the paper.)
* Now introduce the NUMBER LINE! Explain that (like tallying), every time you count something, move one forward on it.
* Ask apprentices to count how many X there are in their environment. (How many people in your room? How many doors? How many fingers do you have? How many ears do you have?) => Continue with more advanced asks with subquestions, if wanted.
* CUT OUT numbers. Give them to the apprentice in random order/orientation. They must put them in sequence. (PERHAPS there is some extra drawing on the tiles, so that when you do it correctly, a large worm shows up or something. And there are 5+ different sets of these to prevent memorization.)
* CONNECT numbers with their quantity => The page shows a bunch of groups of things; place the correct number on the correct group.
* (CONNECT DOUBLE PUZZLE => There are 1,2,...,N of a specific type on the page. Those same numbers are written on the page as well. You must figure out which type appears 2 times, then cross off the 2. Which appears 3 times, then cross off the 3. And so forth, until completely done.)
* NAMING numbers? The resource can _teach_ this. Just ... show it. But feels like this requires quizzes to properly test ...
* Simply HIDE a symbol X times around the entire set of material, then ask at the end "how many SYMBOLHERE are there?" (And you know you have the correct number because it matches the page number of this final page or something.)
* DOMINO MATCHING => This is not actually a _game_, so it fits here. But it tests converting different representations of numbers, matching, etcetera. It's a great great way to cap it off and solidify understanding
* (Does this fit here? **Numerical Patterns**, including Seasons, Day/Night/Calendar. "Create your own pattern", "Continue the pattern", "Solve the puzzle following these patterns")

**Advanced Spells:**
* (Explorers) The Mathemagician (something about numbers being magic, "and so he counted the sheep, there were ___ of them. And suddenly they started to fly!")
* (Quizmasters) Quiz of Quantity ( = Convert visual to number (visual is given as hand, or dice, or tallying, or just a set of objects), Hear the SOUND of a number and pick the right one, SEE a number and pick the written version of it)
* (Puzzlepages)
  * Number Mazes => Find a way through the maze by picking the option that is one HIGHER or one LOWER than where you are now. (Later on, this can be extended to bigger steps and such.)
  * Can we start with small Sudokus here? Maybe ones that ONLY do row/column?
  * Those "bridge" puzzles, perhaps simplified, might also work here (very thematic, very light on math).
  * We can quite easily create Season (logic) puzzles => they must follow each other in the right order, and each set of 4 seasons creates a "year", etcetera
  * SIMILARLY (maybe even easier), we can do DAY/NIGHT puzzles. (You have the Moon-or-Sun Nikoli puzzle, but it's not really what we're looking for ...)
  * CODE BREAKER puzzles (extremely simple, solve physically) => it's just something like "1 2 4 8" and you give the next number. Or "1 5 8 = COW", and you must translate another set of numbers (this just reinforces alphabet position in its simplest form, or asks you to count the 1st/5th/8th letter in the exercises, or whatever.)
* (Runaways) Basically combines several code breaker puzzles + name for digits, and the end result/key-lock is always some "magic number".
* (Gamiverses?)
  * Give a "board game", like Candy land, which is a path on which you move a pawn/token. At the start, the numbers are all given. (If you throw a 3 here, you move to square X.) But this dissolves as you get further, until at the end, you need to fully count yourself.
  * The DICE in this game use the ancient method: just X different tokens that can either land RED SIDE UP or BLUE SIDE UP. After throwing, count the number of reds, and that's how much you move.
