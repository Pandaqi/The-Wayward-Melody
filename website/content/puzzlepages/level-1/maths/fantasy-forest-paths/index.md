_Fantasy Forest Paths_ are a unique kind of puzzle we developed. Each path is a simple challenge for young kids (pre-readers) about learning to **compare and contrast**. Our invention takes this fundamental skill as close to an engaging puzzle game as it can possibly go.

How does each "path" work?

* You play as an animal character with a simple and unique "quirk". For example, "The Hungry Fox" will always choose the path with MORE food.
* Starting from your current location, move from crossroads to crossroads. Draw a path that makes the correct comparisons/choices at each one.
* If you did it right, the path ends at the (secret) home of the animal! Yay!

It tests the skill numerous times, while allowing fun stories, diverse rules, and automatically checking if you did it right. (In many cases, you can even do the same path multiple times, switching to a _different_ animal.)
