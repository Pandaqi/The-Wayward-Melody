This is a **mini escape room** about **rhyme (and alliteration)**! As usual, the product images can explain this far better than words can. But here's the summary:

* Players get a page full of images, which represent possible "suspects" for robbing the bank. (This is a bit tongue in cheek, like the whole escape room, because some suspects are just ... common objects.)
* The solution to every puzzle is a specific **image** (which represents a recognizable _word_). All suspects that rhyme with the solution must be crossed off.
* Until, at the end, only a _single_ suspect remains! You've caught them and saved the day!

As expected, all the puzzles apply one simple trick or twist to rhyming. The goal is for Apprentices to have fun while practicing these skills, not to sit around a table being stumped for 15 minutes. We've designed the escape room such that you can leave out puzzles if you believe they're too hard or would make the activity too long.

We're very proud that we were able to create an escape room, for pre-readers, around this topic. We hope you enjoy it too!
